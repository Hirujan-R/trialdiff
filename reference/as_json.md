# Machine-readable report data

Machine-readable report data

## Usage

``` r
as_json(x, pretty = TRUE, ...)
```

## Arguments

- x:

  A `tdiff`, `td_impact` or `td_report` object.

- pretty:

  Pretty-print JSON.

- ...:

  Unused.

## Value

For `as_json()`, a JSON string. For `as_report_list()`, a list.
